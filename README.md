  ## 项目简介
  
  InstantNote 灵感便签是一个基于 **HarmonyOS / ArkTS / DevEco Studio** 的轻量便签应用。本项目作为开源软件课程结课作业，在社区已有 InstantNote 项目的基础上进行二次开发，并参考 floral-notepaper 的轻量便签风格，使用 Agent 辅助完成 UI 重构、置顶功能、响应式适配和局域网投送流程设计。
  
  本项目希望实现一个轻量、清晰、适合手机 / 平板 / 2in1 使用的便签工具：**打开即记、快速整理、重点置顶，并探索只依赖本软件完成局域网面对面投送的能力**。

  | -------------- | ---------------------------------------------------- | ------------------------------------ |

  | 本地存储       | `entry/src/main/ets/common/MemoStorage.ets`          | 负责便签的本地保存与读取             |
  | 投送协议       | `entry/src/main/ets/common/MemoTransfer.ets`         | 投送包编码、解码、预览和合并         |
  | 会话管理       | `entry/src/main/ets/common/TransferLanSession.ets`   | 生成确认码、会话 ID、摘要和过期时间  |

  ## 架构概览

  ```text
  用户输入 / 编辑便签
          ↓
  MemoModel 数据结构
          ↓
  MemoStorage 本地保存
          ↓
  首页列表 / 搜索 / 置顶排序
          ↓
  投送中心选择范围
          ↓
  MemoTransfer 编码为文本 payload
          ↓
  TransferLanSession 创建确认码和会话
          ↓
  TransferLanDiscovery 发布 / 搜索服务
          ↓
  TransferLanTransport 本机回环或后续真实传输
          ↓
  decodeTransferPackage
          ↓
  previewTransferImport
          ↓
  用户确认
          ↓
  mergeReceivedMemos
  ```
  
  核心设计原则：
  
  - **UI 与协议分离**：投送中心只负责交互，投送包处理集中在 `MemoTransfer.ets`。
  - **发现与传输分离**：mDNS 只负责发现服务，payload 获取由传输层负责。
  - **导入必须预览**：接收内容后不能直接合并，必须先进入导入预览。
  - **不伪装真实双机能力**：单模拟器环境下只做本机回环验证，不声称已完成真实跨设备投送。

  ## 构建与运行
  
  1. 使用 DevEco Studio 打开项目根目录。
  2. 等待 ohpm / hvigor 同步完成。
  3. 选择 `entry` 模块。
  4. 选择 HarmonyOS phone、tablet 或 2in1 模拟器。
  5. 点击 Run 运行项目。
  
  命令行构建可执行：
  
  ```powershell
  D:\DevEcoStudio\tools\hvigor\bin\hvigorw.bat assembleApp
  ```
  
  权限说明：

  | 权限                       | 用途                                      |
  | -------------------------- | ----------------------------------------- |
  | `ohos.permission.INTERNET` | 局域网发现与后续文本 payload 传输能力探索 |
  
  当前项目不会申请相机权限，不使用扫码作为主流程，也不依赖微信、QQ、邮件等外部软件完成投送。
