- # InstantNote 灵感便签

  > HarmonyOS / ArkTS / DevEco Studio  
  > 轻量记录，随手整理；让每一条灵感都能被保存、检索、置顶与投送。

  InstantNote 灵感便签是一个基于 HarmonyOS / ArkTS 的轻量便签应用。本项目作为开源软件课程结课作业，在社区已有 InstantNote 项目的基础上进行二次开发，并参考 floral-notepaper 的轻量便签风格，使用 Agent 辅助完成 UI 重构、置顶功能、响应式适配和局域网投送流程设计。

  本项目希望实现一个轻量、清晰、适合手机 / 平板 / 2in1 使用的便签工具：打开即记、快速整理、重点置顶，并探索只依赖本软件的局域网面对面投送能力。

  ## 设计初衷

  在开源软件课程开发过程中，我希望完成一个既能体现 HarmonyOS / ArkTS 工程能力，又具有实际使用场景的小应用。

  原始 InstantNote 已经具备便签记录的基础形态，但界面、交互、响应式适配和跨设备能力都还有进一步扩展空间。因此，本项目围绕以下目标进行改造：

  1. 将便签应用从“能用”改造成“更像产品”。
  2. 增加搜索、置顶、快速记录等高频便签能力。
  3. 针对 HarmonyOS phone / tablet / 2in1 做响应式适配。
  4. 设计并实现局域网面对面投送的 UI、协议层、会话层和本机回环验证。
  5. 记录 Agent 辅助开发过程，体现开源软件课程中的协作与迭代。

  ## 架构设计

  ### 整体数据流

  ```text
  用户输入 / 编辑便签
          ↓
  MemoModel 数据结构
          ↓
  MemoStorage 本地保存
          ↓
  首页列表 / 搜索 / 置顶排序
          ↓
  投送中心选择范围
          ↓
  MemoTransfer 编码为文本 payload
          ↓
  TransferLanSession 创建确认码和会话
          ↓
  TransferLanDiscovery 发布 / 搜索服务
          ↓
  TransferLanTransport 本机回环或后续真实传输
          ↓
  decodeTransferPackage
          ↓
  previewTransferImport
          ↓
  用户确认
          ↓
  mergeReceivedMemos
  ```

  ### 核心设计原则

  - **UI 与协议分离**：投送中心只负责交互，投送包处理集中在 `MemoTransfer.ets`。
  - **发现与传输分离**：mDNS 只负责发现服务，payload 获取由传输层负责。
  - **导入必须预览**：接收内容后不能直接合并，必须先进入导入预览。
  - **图片传输谨慎处理**：当前文本 payload 可验证，图片二进制传输作为后续阶段。
  - **不伪装真实双机能力**：单模拟器环境下只做本机回环验证，不声称已完成真实跨设备投送。

  ### 当前限制

  由于当前开发环境只有单个 DevEco 模拟器，无法完成两台真实 HarmonyOS 设备在同一 Wi-Fi 下的真实互传验证。

  当前尚未完成或尚未验证：

  - 两台真实设备之间的 mDNS 服务发现
  - 两台真实设备之间的 TCP payload 传输
  - 图片二进制跨设备传输
  - 真机网络权限、热点隔离、局域网隔离等异常场景

  因此，本项目当前投送能力应表述为：

  > 已完成局域网投送的 UI、协议层、传输层和单机回环验证；真实双机投送待两台 HarmonyOS 设备进一步验证。

  ## 使用流程

  ### 基础便签

  1. 打开应用进入首页。
  2. 点击「快速记录」创建新便签。
  3. 在编辑页输入标题、标签和正文。
  4. 返回首页，便签自动保存。
  5. 使用搜索框查找便签。
  6. 点击「置顶」将重要便签固定在列表上方。

  ### 投送中心

  1. 首页点击右上角「投送」。
  2. 在发送页选择投送范围。
  3. 点击开启面对面投送。
  4. 查看 6 位确认码、投送摘要和剩余时间。
  5. 在接收页可以搜索真实设备，或在单模拟器环境下使用单机演示当前发送会话。
  6. 输入确认码进行演示校验。
  7. 使用本机回环传输测试验证 payload 请求、解码和导入预览链路。

  ## 构建与运行

  1. 使用 DevEco Studio 打开项目根目录。
  2. 等待 ohpm / hvigor 同步完成。
  3. 选择 `entry` 模块。
  4. 选择 HarmonyOS phone、tablet 或 2in1 模拟器。
  5. 点击 Run 运行项目。

  命令行构建可执行：

  ```powershell
  D:\DevEcoStudio\tools\hvigor\bin\hvigorw.bat assembleApp
  ```
